Method notes and limitations

• The audit-support skill directs Shopify retrieval through the aw-shopify:shopify-store plugin skill. That skill was not resolvable in this run (the plugin is installed but the skill did not load), so Shopify data was pulled via the Shopify MCP connector — the fallback the audit-support skill itself specifies. Flagging the deviation for transparency.
• Monday.com activity_logs retain roughly 30 days, so stage-change dates for deals won before ~1 July are inferred from updated_at and are upper bounds.
• Country codes are inferred from phone dialling prefixes only. +1 cannot distinguish US from Canada — Tony Ivanoff's +1250 number is a British Columbia area code.
• Monday.com status filters silently return zero when given label text instead of a label index. All filter-based counts here were re-run with numeric indexes and cross-checked against a full manual tally.
• The 7 oldest allocations reached “Allocation(s) Offered” without passing through “Submitted Full Application” (Mohit Parikh, Andrew Kamarchevakul, Istvan Kormos, Ju Tan, Abdulla Shareef, Vimal Reddy, Jorge Valdés Cardona). If the Tally application is meant to gate allocation, that gate is being bypassed or the stage is not written on submission.
